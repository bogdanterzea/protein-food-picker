PROTEIN ATLAS SIBIU — DATA SCHEMA (v1)

This file is the contract. Every data file in js/data/ must follow it exactly. The web app reads these fields by name. A missing or misspelled field = a broken card.

1. File format

Every data file is plain browser JavaScript (NOT an ES module — the site must work from file:// with no build step and no server). Wrap everything in an IIFE that appends to a global array:

/* =========================================================================
 * PROTEIN ATLAS SIBIU — <CATEGORY TITLE>
 * File: js/data/NN-slug.js
 * Items: <count>
 * Category slug: <category-slug>
 * ID prefix: <x->
 * Last researched: 2026-08
 * ========================================================================= */
(function () {
  'use strict';

  const ITEMS = [

    { /* ...entry 1... */ },
    { /* ...entry 2... */ },

    // ---INSERT-NEW-ITEMS-ABOVE---
  ];

  window.PF_FOODS = (window.PF_FOODS || []).concat(ITEMS);
})();

Keep the literal line // ---INSERT-NEW-ITEMS-ABOVE--- in the file. It is the anchor you use to append further batches with the Edit tool, so you never have to rewrite the whole file.

Hard rules

  • Must be valid JavaScript. If it does not parse, the whole site breaks.
  • Numbers are plain numbers, never strings. protein: 21.5 not protein: "21.5".
  • No NaN, no null for numbers — use 0 when genuinely zero, and omit an optional object only if the schema says it is optional.
  • UTF-8, Romanian diacritics welcome (ă â î ș ț), exactly one emoji in emoji.
  • Do not use backticks inside strings. Use single quotes for strings; escape internal apostrophes ('Kaufland\'s') or just use double quotes for that string.
  • Every id must be globally unique. Use your assigned prefix.

2. The entry schema

{
  // ---- IDENTITY -------------------------------------------------------
  id: 'd-skyr-natural-milbona',   // kebab-case, unique, starts with your prefix
  name: 'Skyr, Plain',            // English common name
  nameRo: 'Skyr natural',         // the name as printed on the Romanian shelf label
  brand: 'Milbona (Lidl)',        // brand + retailer in parens; 'generic' if unbranded
  category: 'dairy-eggs',         // YOUR fixed category slug — identical in every entry
  subcategory: 'Iaurturi & brânzeturi proaspete',  // Romanian, free text, reused across similar items
  emoji: '🥛',                    // exactly ONE emoji, used as the card icon
  unit: 'g',                      // 'g' for solids, 'ml' for liquids. per100g is per 100 of this unit.

  // ---- WHERE TO BUY IT IN SIBIU --------------------------------------
  stores: [
    {
      name: 'Lidl',               // see controlled store list below
      availability: 'always',     // 'always' | 'usual' | 'seasonal' | 'occasional' | 'online'
      aisle: 'Raft lactate, lângă iaurturile grecești',  // Romanian, where to physically look
      priceRon: 5.99,             // pack price in RON, 2026 estimate. 0 if truly unknown.
      packGrams: 450,             // NUMBER of grams (or ml) in that pack. Required if priceRon > 0.
      packLabel: 'caserolă 450 g',// human label for the pack
      note: ''                    // optional short note, '' if none
    }
    // 1–5 store entries. List the CHEAPEST / most reliable first.
  ],
  sibiuNote: 'Toate cele 4 magazine Lidl din Sibiu îl au...',  // Sibiu-specific practical tip

  // ---- NUTRITION (per 100 g or 100 ml of the product AS SOLD) ---------
  per100g: {
    kcal: 63,        // kilocalories
    protein: 11,     // g
    carbs: 4,        // g (total carbohydrate, EU style = excluding fiber)
    sugars: 4,       // g, must be <= carbs
    fat: 0.2,        // g
    satFat: 0.1,     // g, must be <= fat
    fiber: 0,        // g
    salt: 0.1        // g of salt (NOT sodium). salt = sodium * 2.5

  // Optional but valuable — include when meaningful, else omit the whole object:
  micros: {
    calciumMg: 150,     // omit any line you do not know
    ironMg: 0.1,
    zincMg: 0.6,

    vitDUg: 0,

    cholesterolMg: 5

  // Fraction (0–1) of the declared protein that comes from collagen/gelatin.
  // Omit it entirely for everything else; see the note under the schema.
  collagenShare: 0.33,

  // ---- PORTION --------------------------------------------------------
  serving: {
    grams: 200,                    // a realistic single portion, in the same unit as above
    label: '1 caserolă mică (200 g)'  // Romanian

  // ---- EFFORT & TIME --------------------------------------------------

  cooking: {
    method: 'none',   // 'none' | 'reheat' | 'boil' | 'pan' | 'grill' | 'oven' | 'airfryer'
                      // | 'slow' | 'pressure' | 'blend' | 'assemble' | 'soak' | 'fry' | 'steam'
    difficulty: 'none',  // 'none' | 'trivial' | 'easy' | 'medium' | 'hard'

    steps: [             // Romanian imperative steps. 0 steps if ready-to-eat, else 2–8 steps.

collagenShare — when a product is only partly gelatin

Collagen and gelatin contain no tryptophan, so the app writes their protein down to a factor of 0,25 (see docs/METHODOLOGY.md §4). It normally recognises them from the name — colagen, gelatină, piftie, răcituri, aspic, plus the cuts that are structurally collagen without saying so: burtă / tripe, tendon, șorici.

That works for a product that is collagen. It fails for a product that merely contains some, and it fails hard, because the whole entry drops to 0,25:

// b-jeleu-proteic — 15 g gelatină + 30 g whey per ~450 g of jelly
per100g: { kcal: 40, protein: 8.5, /* … */ },
collagenShare: 0.33,   // ~2,8 g of the 8,5 g protein is gelatin; the rest is whey

Without the field, the word "gelatină" in the name pushed this dessert to rank E. With it, the quality factor becomes a weighted average — 0,33 × 0,25 + 0,67 × 0,92 = 0,70 — and it lands at rank D, which is what a 40 kcal / 8,5 g-protein dessert actually deserves.

Rules:

  • Omit the field unless the product genuinely mixes the two protein pools. The name-matching stays the fallback, so leaving it out changes nothing.
  • collagenShare: 1 is identical to being caught by the name — use it only when the name would not catch a pure-collagen product.
  • Estimate it from the recipe or the ingredient list, in grams of protein, not grams of ingredient (gelatin is ~86 % protein, whey isolate ~90 %), and write the arithmetic in a comment next to the field.
  • The dossier still shows the red "proteină incompletă" warning and the product is still excluded from the protein leaderboards. Only the score is nuanced.

4. Quality bar — read this twice

  1. Real products, real shelves. Every branded item must plausibly exist in a Lidl, Kaufland, Carrefour, Profi, Penny, Mega Image, Auchan, Selgros or Metro in Romania in 2025–2026. When unsure whether a brand/product is sold in Romania, web-search it before including it. If you cannot confirm, either drop it or set dataConfidence: 'medium' and use the generic type name instead of a fake SKU.
  2. Never invent a nutrition label. If you are not confident of the exact numbers, use well-established generic values for that food type (USDA/CIQUAL-style) and set dataConfidence to 'medium'. Internal consistency is checked by the app: kcal ≈ protein*4 + carbs*4 + fat*9 + fiber*2 (±15 %). Entries that fail this badly will be flagged, so sanity-check your arithmetic.
  3. sugars ≤ carbs and satFat ≤ fat. Always.
  4. Prices are 2026 Sibiu estimates in RON. Reasonable ranges: chicken breast ~30–40 RON/kg, eggs ~1.2–1.8 RON each, Greek yogurt ~4–9 RON/pot, canned tuna ~7–14 RON/tin, whey ~150–320 RON/kg. Don't produce absurd numbers.
  5. Diversity beats duplication. Ten near-identical Greek yogurts is a waste. One per meaningfully different product (different brand tier, fat level, or format) is fine.
  6. Be honest in stats and taste. Liver is a protein monster with a taste score of 25. Plain chicken breast is boring: taste 45. Say so.
  7. Romanian for user-facing prose (aisle, steps, tips, taste.*, storage, warnings, pairings, subcategory, sibiuNote, timingNote). English for name, tags, enums and slugs.

5. Companion documentation

Each data file has a sibling markdown file in docs/categories/<category-slug>.md, 250–450 lines, containing:

  • A short intro on why this category matters for protein.
  • Buying guide for Sibiu — which store wins for what, when to go, what to avoid.
  • Top 10 picks table (name | protein/100 g | kcal | RON/kg | protein per RON | verdict).
  • Traps & marketing lies in this category.
  • 4–8 recipes / preparation protocols with timings, in Romanian.
  • Storage & food-safety notes.
  • A price-per-gram-of-protein ranking table.
  • Sources / how the data was gathered, and known uncertainty.

Write it in Romanian with English technical terms where natural.
